Overview

Marus Widgets ("we," "our," or "us") provides custom livestream widgets and creator tools, including live viewer counters and multi-platform live chat aggregation for supported streaming platforms such as Twitch, Kick, and YouTube.
We are committed to protecting user privacy and handling publicly available information responsibly.

Information We Collect

Marus Widgets only accesses publicly available information necessary to provide widget functionality. This may include:

  • Public livestream chat messages
  • Public usernames and display names
  • Public profile images
  • Public livestream information
  • Public viewer counts
  • Public channel information
  • Public platform badges and publicly available user metadata

We do not collect or store:

  • Passwords
  • Payment information
  • Private account information
  • Google account credentials
  • OAuth tokens (unless explicitly implemented in a future version)

YouTube API Services

Marus Widgets uses the YouTube Data API to provide real-time livestream functionality, including public live chat messages and live viewer counts.
By using features powered by YouTube, you acknowledge that your use of those features is also subject to the Google Terms of Service Policy.
Marus Widgets only accesses publicly available YouTube information required to provide the requested functionality.

How Information Is Used

  • Display live chat within custom streaming overlays
  • Display public livestream statistics
  • Display real-time viewer counts
  • Provide live widget functionality
  • Improve the performance and reliability of supported widgets

Information is never used for advertising, profiling, or marketing purposes.

Data Storage

Marus Widgets does not permanently store livestream chat messages, viewer counts, or public livestream metadata. Information is processed temporarily in memory or short-term cache solely to provide real-time functionality and is discarded after use.

Data Sharing

We do not sell, rent, or share personal information with third parties. Information obtained through supported platform APIs is used only to provide the requested widget functionality.

Data Deletion

Because Marus Widgets does not permanently store livestream chat messages, viewer counts, or other public livestream data, there is generally no persistent user data to delete. If future versions store user-specific information, users may request deletion by contacting us.

Security

  • API credentials
  • Cloudflare Worker infrastructure
  • Services used to provide widget functionality

Access is limited to what is necessary for operation of the service.
