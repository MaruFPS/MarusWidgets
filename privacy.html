Overview

Marus Widgets ("we," "our," or "us") provides custom livestream widgets and creator tools, including live viewer counters and multi-platform live chat aggregation for supported streaming platforms such as Twitch, Kick, and YouTube.

Information We Collect

  • Public livestream chat messages
  • Public usernames and display names
  • Public profile images
  • Public livestream information
  • Public viewer counts
  • Public channel information
  • Public platform badges and publicly available user metadata

YouTube API Services

Marus Widgets uses the YouTube Data API to provide real-time livestream functionality.

Data Storage

Information is processed temporarily in memory or short-term cache solely to provide real-time functionality and is discarded after use.
