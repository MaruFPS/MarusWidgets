Privacy Policy
Last Updated: August 8, 2026

Overview

Maru Widgets ("we," "our," or "us") provides custom livestream widgets and creator tools, including live viewer counters and multi-platform live chat aggregation for supported streaming platforms such as Twitch, Kick, and YouTube. This Privacy Policy explains what information our API Client accesses, collects, stores, processes, and otherwise uses.

YouTube API Services

Maru Widgets uses YouTube API Services, including the YouTube Data API, to provide real-time livestream functionality such as public live chat messages and public live viewer counts. Use of YouTube-powered features is also subject to the Google Privacy Policy.

Information and API Data We Access

Maru Widgets accesses only the information necessary to provide the requested widget functionality. Depending on the platform and widget being used, this may include:

  • Public livestream chat messages
  • Public usernames and display names
  • Public profile images
  • Public livestream titles, identifiers, and status information
  • Public live viewer counts
  • Public channel information
  • Public platform badges and other publicly available user metadata
  • YouTube API Data returned by the YouTube API Services for the requested public livestream or channel

Current public YouTube widget functionality does not require users to provide Maru Widgets with Google account passwords or Google account credentials. Maru Widgets does not collect payment information through these widgets.

How Information Is Used

Information and API Data accessed through supported platforms is used only to:

  • Display live chat within custom streaming overlays
  • Display public livestream statistics and live viewer counts
  • Identify the public livestream or channel requested by the user
  • Provide and maintain real-time widget functionality
  • Improve the performance, reliability, and error handling of supported widgets

Maru Widgets does not use YouTube API Data for advertising, profiling, or unrelated marketing purposes.

Data Storage and Processing

Maru Widgets does not permanently store public livestream chat messages, public viewer counts, or public livestream metadata. This information may be processed temporarily in memory or short-term cache only as needed to provide real-time functionality and reduce unnecessary API requests, and is then discarded or refreshed.

Cookies, Browser Storage, and Third-Party Technologies

Maru Widgets does not intentionally place first-party advertising or tracking cookies for its YouTube widget functionality. However, the Maru Widgets website and widgets may load content or resources from third-party service providers, such as GitHub Pages, Google Fonts, image-hosting providers, Cloudflare, YouTube/Google, StreamElements, or other supported streaming services. Those third parties may receive standard browser or device information, such as an IP address, browser or user-agent information, referrer information, or similar request metadata, and may place, access, or recognize cookies or similar technologies according to their own policies. Users should review the privacy policies of those third-party services for additional information.

Data Sharing

Maru Widgets does not sell or rent personal information. Information obtained through supported platform APIs is used to provide the requested widget functionality. Information may necessarily be transmitted to infrastructure or service providers used to operate the widgets, such as Cloudflare, hosting providers, or the relevant streaming platform, solely as required to provide the service.

Google Authorization, Revocation, and Data Deletion

Current public YouTube widget functionality is designed to use publicly available, non-authorized YouTube API Data and does not require a user to grant Maru Widgets OAuth access to a Google account. If a current or future Maru Widgets feature accesses Authorized Data through Google user authorization, users may revoke Maru Widgets' access through Google's security settings at Google Account Connections.

Users may also request deletion of any user-specific or Authorized Data stored by Maru Widgets by contacting evolvexdesigns@gmail.com. If Authorized Data is stored in a feature that uses Google authorization, Maru Widgets will delete data associated with that authorization after revocation or a valid deletion request as soon as reasonably possible and in accordance with applicable YouTube API Services policies.

Because the current public livestream widgets do not permanently store public chat messages, viewer counts, or public livestream metadata, there is generally no persistent public livestream data to delete.

Security

Reasonable administrative and technical measures are used to protect API credentials and the infrastructure used to provide widget functionality, including Cloudflare Worker services and other supporting systems. Access is limited to what is necessary for operation of the service.

Changes to This Privacy Policy

This Privacy Policy may be updated periodically. Any changes will be posted on this page along with an updated revision date.
